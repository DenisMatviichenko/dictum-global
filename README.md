# Dictum Global — сайт

Статичний сайт (HTML + CSS + JS, без фреймворків) у стилі «чорний · олива · золото».

## Як відкрити
Подвійний клік по `index.html`. Усі посилання відносні — сайт працює локально і на будь-якому хостингу.

## Структура
```
index.html              головна
praktyky/               14 практик + перелік («Послуги»)
haluzi/                 14 галузей + перелік
produkty/               4 продукти + перелік
pro-nas.html            про компанію, експерти, нагороди
klienty.html            клієнти
novyny/                 новини (пошук, рубрики) + стаття SAF-T UA
kontakty.html           офіси та форма
404.html, sitemap.xml, robots.txt
css/style.css           дизайн (кольори — змінні на початку файлу; оливковий #778C30)
js/main.js              меню, анімації, карусель відгуків, FAQ, підказка «Чим можемо бути корисними», форми
img/                    фото (згенеровані в Figma AI) і favicon
_source/                генератор сторінок і тексти — НЕ завантажувати на хостинг
```

## Форми та підказка
Форма на сторінках і спливаюча підказка справа поки без сервера: після перевірки полів відкривається поштовий клієнт
з листом на info@dictum.ua. Щоб заявки надходили напряму (Formspree, PHP-скрипт хостингу, CRM, Telegram-бот),
вкажіть адресу обробника в атрибуті `data-endpoint=""` у `_source/generate.py` (функції `contact_form` і `tip`)
і перезберіть сайт. Дані надсилаються як JSON POST.

Підказка з’являється, коли відвідувач прогортає сторінку (або через 6 секунд). Після закриття
лишається кругла кнопка в кутку; повторно підказка не вискакує до кінця сесії.

## Мови
Сайт має 4 мовні версії: українська (корінь сайту), англійська (`/en/`), турецька (`/tr/`) і російська (`/ru/`).
Перемикач UA · EN · TR · RU у шапці веде на ту саму сторінку іншою мовою; для пошуковиків додано hreflang.
- Тексти практик, галузей і продуктів: `_source/*.en.txt`, `*.tr.txt`, `*.ru.txt` (той самий формат, що й українські).
- Написи інтерфейсу, меню, головна, команда, новини: словник `_source/i18n.py` (український текст → EN, TR, RU).
- Повідомлення скриптів (помилки форм тощо): словник на початку `js/main.js`.
Переклади зроблено як чернетку — перед запуском варто дати їх вичитати носіям мови або юристу.

## Як змінити тексти
- Практики, галузі, продукти: `_source/practices*.txt`, `industries.txt`, `products.txt`.
- Команда, клієнти, новини, офіси: `_source/content.py`.
- Блоки головної (відгуки, FAQ, таблиця порівняння): `_source/generate.py`.
Після змін: `python3 _source/generate.py` — перезбирає всі 4 мовні версії.

## Що доробити
- Відгуки: у каруселі стоять заглушки «[Текст відгуку клієнта…]» — замініть на реальні цитати (`REVIEWS` у generate.py).
- Фото команди: зараз монограми з ініціалів.
- Статті: окрема сторінка лише для SAF-T UA, інші новини ведуть на поточний dictum.ua.
- Версії EN / TR поки ведуть на поточний сайт.
